Quillo — "Your fridge is waiting" Email Card
============================================

Files:
  index.html               → open this in any browser to view the card
  assets/quillo-hand.woff2 → handwriting font (Caveat, subset) used for the
                             top-right note and the "Small scans..." note

Notes:
  - index.html references the assets/ folder, so keep index.html and
    assets/ together in the same location.
  - The phone + receipt, the green "Takes less than 30 seconds" badge, the
    gift/scan icons and the "Why do it now?" icons are all inline SVG in
    index.html (no image files needed).
  - Colors are defined as CSS variables in the :root { } block at the top
    of index.html. Text can be edited directly in the HTML.
